# E-Commerce-Sales-Dashboard
Create e-commerce sales dashboard using excel.
Create e-commerce report for month Jan, fab and march.
Create KPI on Total orders, Total Quantity, Amount, Average rating and Average days to delivered by each order mode.
Create slicer on order mode to identify from where we get more orders.
Analyze the sales trend, Popular products, How many quantities customers buy, Orders mode that customers preferred more.
How long we take to delivered the orders, where our customers live and customers ratings.
